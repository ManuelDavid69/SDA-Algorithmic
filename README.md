# SDA Algorithmic

Practical work for the **Data Structures and Algorithms** course at CPE Lyon
(3IRC, 2025/2026), rewritten in Python.

The repository follows the eight course sessions, from linked lists and stacks
to AVL trees, graph theory and Dijkstra's shortest-path algorithm.

> The exercise statements are part of the course material. This repository
> contains the implementations, tests and written answers produced for them.

## Practical work

| # | Topic | Code |
|---|---|---|
| 1 | Linked lists, stacks, train simulation | `src/sda/tp01_data_structures` |
| 2 | Complexity and benchmarks | `src/sda/tp02_complexity` |
| 3 | Recursion, divide and conquer | `src/sda/tp03_recursion` |
| 4 | Sorting algorithms | `src/sda/tp04_sorting` |
| 5 | Binary search trees, expression trees, Akinator | `src/sda/tp05_trees` |
| 6 | Hash tables, AVL trees, vinyl catalogue | `src/sda/tp06_associative_arrays` |
| 7 | Graph theory | `src/sda/tp07_graphs` |
| 8 | NetworkX and Dijkstra | `src/sda/tp08_networkx` |

Details will be added as the sessions are completed.
